# 前端视觉规范（V0.1）

来源：`design/room.html`（桌面房间）、`design/mobile.html`（手机房间）、`design/join.html`（入房）。
风格基准：吉卜力（柔和自然）+ 便当盒式分区；规则冲突时以「禁止项」优先，见文末。

## 2. 字体与字号

- 字族：`"Noto Sans SC", "Microsoft YaHei", system-ui`；数字与时间用 `ui-monospace`。
- 行高：正文 1.6–1.7；标题 1.3。

| 层级 | 尺寸 | 字重 | 用途 |
| --- | --- | --- | --- |
| 页面标题 | 44px | 700 | 入房页主标题 |
| 区块标题 | 16px | 700 | 聊天、房间、AI 导播 |
| 名片姓名 | 13.5px | 600 | 成员卡 |
| 消息正文 | 14px | 400 | 聊天气泡 |
| 元信息 | 10.5–12px | 400 | 时间、标签、说明 |

小字下限 10px（仅限时间戳等非交互文本），正文不小于 13.5px。

## 3. 形状与阴影

| 元素 | 圆角 |
| --- | --- |
| 大卡（聊天、侧栏） | 34–42px，四角不对称 |
| 成员名片 | 14–16px |
| 气泡 | 16–22px，靠说话人一侧收小角 |
| 按钮 | 12–16px |
| 头像 | 不规则椭圆 `52% 48% 45% 55% / 48% 52% 48% 52%` |

阴影只用带色的柔和扩散，不用黑色投影：
`0 2px 8px rgba(124,185,168,.15)` / 悬停 `0 10px 28px rgba(124,185,168,.3)`。

## 4. 动效

| 场景 | 时长 | 曲线 |
| --- | --- | --- |
| 卡片悬停 | 500ms | `ease-in-out`，上浮 3px + 0.12° 微旋 |
| 名片发言 | 1000ms | 上浮 6px、放大 1.12、色环扩散一次 |
| 气泡飞行 | 660–680ms | `cubic-bezier(.45,.05,.55,.95)`，二次贝塞尔路径，全程 ±1.2° 摆动 |
| 菜单／弹窗出现 | 280–300ms | `ease-out`，位移 6px + 淡入 |

同一页面只允许一个「正在动」的主角；`prefers-reduced-motion: reduce` 时全部退化为直接到达终态。

## 5. 组件要点

- **成员名片**：头像（角色色）+ 姓名 + 兴趣标签（cap 层数据 `interestTags`）+ 右上角状态（在线／倒计时）。掉线时虚线框、状态转珊瑚色。
- **聊天气泡**：按作者上色；AI 用白底虚线；同一作者连续消息不重复头像时可用紧凑行。
- **输入区**：无边框输入 + 一条底部线；输入 `@` 浮出「AI 导播」建议，选中插入 `@AI `。
- **顶部菜单**：`⋯` 展开「邀请／退出房间」；邀请打开二维码 + 复制链接弹窗，退出走二次确认。
- **空态与边界**：房满、昵称重复、邀请失效、被移出、房间关闭都各有终态文案，不共用一句「出错了」。

## 6. 禁止

- 不用纯黑 `#000`、不用蓝紫渐变、不用霓虹高饱和。
- 不用直角与完美正圆（头像用椭圆，卡片用不对称圆角）。
- 不用黑色硬投影、不用 `shadow-xl` 级别的重阴影。
- 不用单侧粗色条做装饰、不用渐变文字、不用玻璃拟态当默认。
- 不在卡片里再套卡片；分区靠发丝线与留白。
- 不做 200ms 以内的硬切动画、不做 bounce／elastic 曲线。
