# 使用全栈 TypeScript 和分层的模块化单体

本项目优先满足敏捷开发和 AI 接入，已确认采用 TypeScript、Fastify、React/Vite 与 AI SDK Core。选择统一语言和独立契约 Schema，是为了减少前后端分别维护类型、校验和联调样例的成本；同时将模型供应商细节留在具体实现中。项目采用前后端分离结构，根级 `frontend/`、`backend/` 分别组织应用，通过独立的 `contracts/` 统一线上协议。后端采用分层的模块化单体，通过小而明确的统一接口接入能力插件，保持业务职责集中和依赖方向清晰；不以仓库协作建议中的 Go 技术栈作为约束。分层与目录设计见 [架构文档](../architecture.md)。
