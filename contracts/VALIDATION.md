# v0.1.0 契约验证记录

验证日期：2026-11-03；本地工具运行于 Node.js 24.19.0。

| 检查 | 结果 |
| --- | --- |
| OpenAPI 3.1 正式规范校验 | 通过，11 个 HTTP／升级操作 |
| 公共模型与样例 | 49 个模型、43 个 HTTP 成功和错误样例通过 JSON Schema 校验 |
| WebSocket 场景 | 12 个场景、56 帧通过 Schema 与时序检查，覆盖全部事件种类 |
| 协议边界 | 串行调用、终态互斥、旧回复可见范围、快照文本归并和关房取消顺序通过 |
| 反例 | 缺失消息标识、空兴趣标签、非法 null 和新成员旧回复泄漏会被拒绝 |
| HTTP Mock 实际请求 | 90 个成功／错误响应与样例一致，浏览器跨域预检通过 |
| WS Mock 实际连接 | 收到 8 帧，首帧快照、文本增量拼接和完整终态通过 |
| TypeScript 消费 | 类型生成成功；独立消费端通过本地包名导入，严格编译检查通过 |

常规复查运行 `npm run check --prefix contracts`；类型重建运行 `npm run types --prefix contracts`。本地 Mock 的启动和场景选择见 [README](README.md)。正式规范检查另使用 openapi-spec-validator，样例同时用独立的 Python JSON Schema 验证器交叉校验。

这些结果确认了接口基线、开发工具和样例可用。真实房间状态、成员鉴权、限频、模型接入与多人业务行为需要前后端完成后，按同一契约进行实际联调验收。
